# Fonts

Each face sets Khmer and Latin, and ships here so the game reads the same on every phone and
offline. All are licensed under the SIL Open Font License 1.1 (`OFL-*.txt`), in the `woff2` files
Google Fonts serves, cut by script.

| Face          | Files                                    | Sets                                                       |
| ------------- | ---------------------------------------- | ---------------------------------------------------------- |
| Moul          | `moul-{khmer,latin}-400-normal.woff2`     | the painted sign, the money pieces' figures, stamps, Give  |
| Fasthand      | `fasthand-{khmer,latin}-400-normal.woff2` | ballpoint: the bills' figures, totals and corrections     |
| Kantumruy Pro | `kantumruy-pro-{khmer,latin}-{400,700}…`  | print: labels, settings, How to play, and the signs × ÷ − |

Moul and Fasthand have no × ÷ − of their own, so a bill sets its sign in Kantumruy Pro.
