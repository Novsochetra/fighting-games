# Fonts

Both faces set Khmer and Latin, and ship here so the game reads the same on every phone and
offline. Each is licensed under the SIL Open Font License 1.1 (`OFL-koulen.txt`,
`OFL-kantumruy-pro.txt`), in the `woff2` files Google Fonts serves, cut by script.

| Face          | Files                                    | Sets                                          |
| ------------- | ---------------------------------------- | --------------------------------------------- |
| Koulen        | `koulen-{khmer,latin}-400-normal.woff2`  | the name, every number, buttons and headings  |
| Kantumruy Pro | `kantumruy-pro-{khmer,latin}-{400,700}…` | sentences: captions, labels, How to play      |
